# DropSystem OS 🟣

Sistema operacional baseado em Debian + Xfce + Wine, feito para ser leve, completo e fácil de usar.

## ✅ Funcionalidades
- Interface Xfce customizada com identidade visual do DropSystem OS
- Wine pré‑instalado para executar arquivos `.exe` do Windows
- Navegador, pacote de escritório, reprodutor de mídia
- Instalador gráfico Calamares
- Tela de boot com a logo do DropSystem OS

## 📥 Baixar a ISO
Acesse a página de [Releases](https://github.com/SEU_USUARIO/dropsystem-os/releases) e baixe a imagem `.iso`.
