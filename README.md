# DropSystem OS 🟣

Sistema operacional baseado em Debian, Xfce e Wine, feito para ser leve, completo e fácil de usar.

## ✅ Funcionalidades

- Interface Xfce customizada com a identidade visual do DropSystem OS
- Wine pré-instalado para executar aplicativos `.exe` do Windows
- Navegador, pacote de escritório e reprodutor de mídia
- Instalador gráfico Calamares
- Tela de boot com a logo do DropSystem OS

## 📥 Baixar a ISO

Acesse a página de [Releases](https://github.com/EmbrasilSeguranca/dropsystem-os/releases) e baixe a imagem `.iso`.

## 🔧 Compilar localmente

```bash
sudo apt install live-build
git clone https://github.com/EmbrasilSeguranca/dropsystem-os.git
cd dropsystem-os
sudo lb build
```
